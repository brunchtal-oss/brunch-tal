# Video data — נתונים בדויים לסרטוני ההסבר

## Description

סיפור חדש (החלטת המשתמשת 2026-10-22): המשתמשת מצלמת סרטוני הסבר לטל (אדמין) וללקוחות (האזור האישי והאתר), באתר הנוכחי מול מסד הפיתוח, לפני 6.1. כותבים מחדש את סקריפטי ההדגמה (demo-seed.mjs, demo-clear.mjs ועזריהם) כך שייצרו עולם בדוי ונקי עם תאריכים מיום ההרצה והלאה, בלי קובץ מזהים מקומי: מפגשים קרובים מכמה קונספטים (אחד מלא עם רשימת המתנה, אחד זוגי), מפגש שהסתיים, לקוחות בדויות עם כרטיסייה, מוצר מוצמד, זיכוי ובקשת החזר, תשלום שממתין לאישור, קישור הצטרפות פתוח, פתקים ודף עבודה, ולקוחה בדויה עם סיסמה ידועה לצילום האזור האישי. כל נתון מסומן כך שאפשר לזהות אותו במסד, ופקודת המחיקה מוחקת רק אותו (בדיקת הגנה: לא נוגעת ב-dev-customer, ב-dev-admin, בנתוני test_ או בכל שורה אחרת). הסקריפט רץ רק מול פרויקט הפיתוח (dev-guard), ונכתב דרך ה-RPC הקיימים ככל האפשר.

## Acceptance Criteria

Verify: הרצה מול מסד הפיתוח: האדמין רואה מפגשים קרובים עם תפוסה, "לטיפול" עם פריטים, תשלום לאישור ורשימת המתנה; הלקוחה הבדויה נכנסת ורואה כרטיסייה, הרשמה קרובה וזיכוי; הרצה שנייה לא מכפילה נתונים; המחיקה משאירה את המסד כפי שהיה לפני ההרצה (ספירת שורות בטבלאות העיקריות).
