# תסריט ההדגמה (סיפור 5.18, חלק א׳)

התסריט בנוי לפי פעולות, לשלוש דמויות: אורחת, לקוחה ואדמין. לכל פעולה כתוב מה עושים, מה רואים ואיזה סיפור היא מדגימה. הנתונים נוצרים ב-`npm run demo:seed` (ההוראות ב-README, "נתוני הדגמה"). כל השמות, המיילים והטלפונים בדויים.

צילומי המסך ומסלול ההצגה הסופי נקבעים בחלק ב׳ (סבב 9). המקומות שלהם מסומנים ב-**[צילום]** וב-**[נוסח]**.

## הנתונים בקצרה

D הוא יום ההרצה הראשונה. התאריכים זזים יחד איתו, ושבת מדולגת.

| מפגש | מתי | קונספט | מה יש בו |
|---|---|---|---|
| E0 | היום (D), נגמר כמה דקות אחרי ההרצה | אמהות בחל״ד | 4 נרשמות, כולן השתתפו (המערכת סוגרת אותו לבד תוך כ-10 דקות) |
| E1 | D+1 | אמהות בחל״ד | 3 נרשמות, כולל שירה (היכרות) |
| E2 | D+3 | יווני | מאיה, אור, וספיר שעוד לא הצטרפה |
| E3 | D+5 | זוגות | ליאת עם בן הזוג (זוגית, 2 מקומות) |
| E4 | D+6 | יווני | ההרשמה של מאיה, שבוטלה |
| E5 | D+7 | אמהות בחל״ד | 10 מתוך 12, כמעט מלא, ודף עבודה מלא |
| E6 | D+9 | אמהות בחל״ד | מאיה ותמר |
| E7 | D+12 | עם סבתוש | ריק |

הדמויות המרכזיות:

- **מאיה ברק** (`maya.barak@demo.example.com`), לקוחת הכניסה: כרטיסייה של 4 כניסות, השתתפה ב-E0, רשומה ל-E2 ול-E6, כניסה אחת פנויה. היא קנתה כניסה בודדת ל-E4 וביטלה אותה, והכניסה חזרה אליה.
- **נועה אברהם:** כרטיסייה שנקנתה לפני 40 יום ופגה ב-D+9, עם כניסות פנויות.
- **ספיר רבינוביץ:** שילמה על E2 ועוד לא הצטרפה. קישור ההצטרפות שלה תקף 48 שעות. רק אחרי שהוא פג (מ-D+2) הרכישה שלה עוברת ל"לטיפול".
- **קרן וייס:** לקוחה קיימת. בקישור של רכישה חדשה היא הקלידה טלפון של לקוחה אחרת שלוש פעמים, והקישור עבר ל"לטיפול".
- שתי לקוחות היכרות (שירה ב-E1, הדר ב-E5), זוגית אחת (ליאת), ועוד בודדות וכרטיסיות. ארבע עם אלרגיה או תזונה מיוחדת, שלוש עם הערה של טל, ותערובת של כן ולא בשתי ההסכמות לצילום.

## לפני ההצגה

- להריץ את `npm run demo:seed` לפחות 15 דקות לפני ההצגה, כדי ש-E0 ייסגר ויופיע "השתתפת".
- כל מצב נכון רק עד יום מסוים, ולכן כדאי להריץ את `demo:seed` יום או יומיים לפני ההצגה. כשהתאריך נופל על שבת, המפגש זז ליום אחרי, וכך גם היום שבטבלה:

| מצב | עד מתי |
|---|---|
| E0 עם "השתתפת" אצל מאיה | תמיד (מכ-10 דקות אחרי ההרצה) |
| E1 ברשימת המפגשים הקרובים | עד D+1. ההרשמה אליו נסגרת כבר ב-D בשעה 20:00 |
| ההרשמה העצמית של מאיה ל-E2 | עד D+3. ביטול עצמי שלה אפשר עד D+1 |
| ספיר "ממתינה להצטרפות" ב-E2 | עד D+3. ב"לטיפול" רק מ-D+2 |
| ליאת ובן הזוג ב-E3 | עד D+5 |
| E5 כמעט מלא (10 מתוך 12), ודף העבודה שלו | עד D+7 |
| הכרטיסייה של נועה ב"עומדות לפוג" | עד D+9, ואז היא פגה |
| ההרשמה של מאיה ל-E6 | עד D+9 |
| E7 ריק | עד D+12 |
| הקישור של קרן ב"לטיפול" | עד שמטפלים בו |
| הכרטיסייה של מאיה בתוקף | עד D+49 |
- אחרי זה, לבנות את ההדגמה מחדש: `npm run demo:clear`, להריץ את הקובץ שנוצר ב-SQL Editor, ואז שוב `npm run demo:seed`.
