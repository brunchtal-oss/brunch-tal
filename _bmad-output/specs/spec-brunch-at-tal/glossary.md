# מילון מונחים

| מונח | משמעות | בקוד |
|---|---|---|
| תשלום | כסף שהתקבל מחוץ לאפליקציה וטל אישרה | payment |
| רכישה שטרם שויכה | תשלום של לקוחה חדשה שאושר, לפני מימוש קישור ההצטרפות | payment, customer_id = null |
| זכות כניסה | זכות להשתתף שנוצרה מתשלום או מיבוא | entitlement |
| כרטיסייה | זכות עם 4 כניסות ותוקף של 7 שבועות (49 ימים) | entitlement, kind=punch_card |
| תפוגה | סוף היום המקומי (Asia/Jerusalem) ביום ה-28 או ה-49 אחרי תאריך הרכישה | expires_on |
| כניסת היכרות | כניסה במחיר מוזל, לביקור ראשון בלבד | intro_only |
| זכות זוגית | הרשמה אחת לשני מבוגרים, לבראנץ׳ שישי מיוחד. תוקף 4 שבועות | party_size=2 |
| מלווה | המבוגר השני בהרשמה זוגית. נשמרות רק הגבלות תזונה, אופציונלי, בלי שם | bookings.guest_details |
| הרשמה | תפיסת מקום במפגש, ממומנת מזכות | booking |
| שריון | כניסה שהוקצתה להרשמה עתידית | movement=reserve |
| ניצול | כניסה שנצרכה בסיום המפגש, גם באי-הגעה | movement=use |
| זיכוי | זכות להירשם לאחד מהמפגשים החלופיים (ברירת מחדל 2, בהגדרות) אחרי ביטול | cancellation_credit |
| חלופה | מפגש מתאים שמוצע במסגרת זיכוי | credit_option |
| קישור הצטרפות | קישור חד-פעמי ליצירת חשבון, תקף 48 שעות | activation_token (join) |
| קישור הפעלה | קישור חד-פעמי ללקוחה מיובאת: סיסמה והסכמה | activation_token (claim) |
| מפגש | בראנץ׳ עם תאריך, שעת התחלה וסיום, ומכסת מבוגרים | event |
| עומדת לפוג | זכות שנותרו לה ימים עד הסף שבהגדרות (ברירת מחדל 10) | expiring_threshold_days |
| לא פעילה | סימון אחרי 3 חודשים קלנדריים בלי פעילות. לא חסומה ולא נמחקת | activity_status |
| תאריך אחרון | הפעילות האחרונה מכל סוג: השתתפות, רכישה או הרשמה | — |
| ייצוא חלקי | ייצוא CSV של הרשימה המסוננת ו/או של עמודות שטל בחרה | — |
| סכום | נשמר כמספר שלם באגורות, מוצג בשקלים (₪) | *_agorot |
| טרם נמסר | שדה אלרגיות והעדפות ריק | dietary_notes = null |
| חלון אישור | הודעת חיווי בצורת שאלה עם צ׳קבוקס, לפני פעולה רגישה | confirm dialog |
| ברירת מחדל | ערך גלובלי בקטלוג או בהגדרות. חל רק על מה שנוצר אחריו | products, business_settings |
| שינוי למקרה מסוים | שינוי ערך בתשלום, זכות, לקוחה או מפגש אחד, בפעולה מפורשת עם אישור ויומן | entitlement_corrections, audit_log |
| תיקון בזכות | שינוי תוקף, יתרה, ימי מימוש או סוג מפגש בזכות אחת | entitlement_corrections, movement=adjust |
| מחיר תצוגה | מחיר שמוצג במפגש. לתצוגה בלבד | display_price_agorot |
| תוכן האתר | כל טקסט ותמונה שיווקיים באתר הציבורי, עם טיוטה ופרסום | content_pages, content_sections |
| פרטי העסק | שם, טלפון ווואטסאפ, כתובת, הוראות הגעה, ניווט והוראות תשלום | content_sections (business_details) |
| טל | בעלת העסק והאדמין | admin |
